# ⚙️ Teoria da Computação

Esse repositório foi criado para o estudo prático dos conceitos da disciplina de Teoria da Computação da Universidade Federal de Campina Grande (UFCG).

O objetivo principal é a transcrição dos modelos teóricos — Autômatos Finitos Determinísticos (AFDs) e Não Determinísticos (AFNs) — em implementações executáveis utilizando a biblioteca Python `automatalib`. Os scripts incluem testes lógicos derivados dos materiais em Google Colab do professor Ricardo Santos.
